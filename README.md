# RSD Masters Student Companion

A production-grade mobile application for RSD Masters students at USTHB.

## Features
- **Verified Authentication**: Matricule + Bac Certificate validation.
- **Academic Dashboard**: Grades, Timetables, Exam Schedules.
- **Course Materials**: Centralized repository for PDFs and media.
- **Social**: Real-time chat, voice notes, and student feed.

## Getting Started

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Start the App**:
    ```bash
    npm run start
    ```
